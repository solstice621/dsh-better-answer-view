## 模型回答

使用 DeepSeek Harness 桌面版 0.2.1-rc.3 和本插件 0.3.1。完整提问见[主 README](../../README.md)，问题没有要求网页、卡片或图表。两个回答分别生成两个独立嵌入块，正文在块之间提供解释或衔接。简单算术对照只返回文字，没有调用展示工具。

截图直接来自浏览器渲染的已保存回答，在截图时裁剪到回答区域；不是设计稿或生成图片。重新提问会受模型配置和生成差异影响，不能保证逐字或逐像素复现。

## 交互演示

交互截图来自 [examples/leveling.html](../leveling.html)，是预先编写的演示，不是模型生成结果。按主 README 的步骤运行 `npm run demo` 后：

1. 保持每日 3 次任务，初始每次奖励 100 XP，三个阶段为 3、12、30 天。
2. 把奖励调为 150 XP，三个阶段变为 2、8、20 天。
3. 刷新页面，确认奖励仍为 150 XP。
4. 点击“将后期需求降低 30%”，后期需求从 9000 降至 6300 XP，保留 150 XP 奖励，结果为 14 天。
5. 选择阶段并点击“讨论当前阶段”，在宿主区域确认追问；未确认前不会提交。

以上计算、刷新恢复、更新后状态保留和发送前确认均经过浏览器操作验证，未出现页面脚本错误。演示的发送只展示捕获文本；安装到 DSH 后才会发送到当前会话。

GitHub README 只能展示这些静态截图，不能在 Markdown 内运行交互控件。
